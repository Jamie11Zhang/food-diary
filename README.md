# Our Little Food Diary 🍰

A cute, warm little website for recording the restaurants, cafés, dessert shops, and more that we visit together. 💕

## Features
- **✏️ Add a memory** — place name, type, date, photo, rough price, dishes tried, how it tasted, a 5-star ⭐ rating, and a notes box.
- **📖 Our records** — browse every memory as scrapbook-style cards, with search, filter by type, and sort by newest / oldest / highest rated. Edit or delete any entry.
- **Warm hand-written style** — baby-blue → buttery-cream background, handwritten fonts, floating food doodles, and a little heart celebration when you save. ✨

## How your data is stored
Everything is saved **locally in your own browser** (`localStorage`) — nothing is uploaded anywhere. Your memories stay on the device you add them on. (So the same memories won't automatically appear on a different device or browser.)

## Running it
It's a plain static site — just open `index.html` in a browser, or visit the GitHub Pages link.

```
index.html   — page structure
styles.css   — the warm, cute theme
app.js       — form, gallery, rating, storage logic
```
